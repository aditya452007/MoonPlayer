☆ What We Are Doing & Why

BloomeeTunes is a Flutter/Dart music app using the same JioSaavn API as MoonPlayer, but its UI/UX feels dramatically more human-crafted and premium. Our analysis identifies exactly what makes it feel that way — and gives step-by-step instructions for porting those patterns into our React/TypeScript codebase.

BloomeeTunes → Strengths

  • 37 specialized widgets vs our 18 generic components
  • 7 semantically-named colors with distinct roles
  • Chart system with resolve state machine (1046 lines)
  • Full album/artist detail views with adaptive layout
  • Staggered list animations on every screen
  • Dedicated DAO/Repository data layer (5-layer architecture)
  • Tab state preservation with independent scroll
  • Dynamic album art color extraction

MoonPlayer → Gaps

  • TrackCard does double-duty as album/artist/playlist card
  • No secondary accent color, no opacity system
  • No chart carousel, no chart detail view
  • No album or artist routes — only PlaylistView exists
  • No staggered entrance animations on any list
  • Components import stores/API directly (no repository layer)
  • Pages re-mount on every navigation (state lost)
  • Color extractor exists but not integrated

01 UI Architecture & Component Hierarchy

20 New Files 13 Modify Core Restructure

BloomeeTunes has 37 specialized widgets vs MoonPlayer's 18 generic components. The core problem: TrackCard does double-duty as album, artist, and playlist card — leading to bloated files, CSS conflicts, and no type-specific rendering.

Component Decomposition

Current (Monolithic)

  • TrackCard — 105 lines, handles 4 data types
  • TrackRow — 135 lines, handles all list items
  • No AlbumCard, ArtistCard, PlaylistCard
  • No SongRow compact variant
  • Empty / error states via inline JSX

Target (Decomposed)

  • AlbumCard — shows year, track count, artist
  • ArtistCard — circular image, genre, listeners
  • PlaylistCard — gradient overlays for special variants
  • SongRow — compact, no gestures, React.memo
  • EmptyState — icon + message + optional action

Grid & Layout System

BloomeeTunes uses ResponsiveBreakpoints.of(context) with pixel-precise viewport-fraction calculations. MoonPlayer uses fixed CSS breakpoints at 768/1024 that cause visual jumps when columns reflow.

  • 4 background levels (void, surface, elevated, overlay)
  • 1 accent (--accent-moon: #6BA3D6)
  • 1 glow (--accent-glow: #E8C87A)

  • Hardcoded rgba() for glass borders

Album Art Color Extraction

BloomeeTunes' palette_generator.dart extracts dominant colors from album art → dynamic radial gradient in player. MoonPlayer's colorExtractor.js exists (Canvas-based) but is not utilized in any UI component.

Implementation: Enhance colorExtractor.js with extractColorPalette() returning top 3 colors → feed into AmbientBackground component (500ms animated gradient transitions when track changes).

Starting point: Apply the design token expansion first (src/styles/index.css), then update GlassPanel with variants, then integrate color extraction. The typography roles and gradient presets can be added incrementally.
